# Security

Please do not report vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) instead.

Of particular interest: bypassing the response signature check (including XML signature wrapping), XXE and other
XML attacks, leaking the private key or password held by `Potpisivac`, and anything that would let a message be sent
that the user did not sign.

Only the latest release is supported.
